# US-0004: 図書館利用者が来館せずに蔵書を予約できる

## Status
Todo

## User Story
As a 図書館利用者, I want 来館せずに利用可能な書誌を予約したい, so that 来館前に借りたい蔵書を確保できる.

## User Benefit
図書館利用者は来館前に読みたい書誌の蔵書を確保できるため、予約手続きのために図書館へ行く必要がなく、確実に借りられる状態で来館できる。

## Acceptance Criteria
- [ ] ログイン済みの図書館利用者は、利用可能な蔵書がある書誌をオンラインで予約できる。
- [ ] 蔵書検索結果には書誌IDが含まれ、図書館利用者は選択した書誌の書誌IDを指定して予約できる。
- [ ] 予約は蔵書ではなく書誌に対して申し込む。
- [ ] 予約成立時に、対象書誌に属する利用可能な蔵書1冊が確保される。
- [ ] 確保された蔵書は、予約した図書館利用者以外へ貸し出せない。
- [ ] 予約成立時に、対象書誌と受付完了が表示される。
- [ ] 予約確定前に利用可能な蔵書がなくなった場合、予約は成立せず理由が表示される。
- [ ] 同一の図書館利用者は同一書誌を重複予約できない。
- [ ] 1人が同時に予約できる書誌は合計3件までとする。
- [ ] ログインしていない場合は予約できず、ログインが必要である旨が表示される。

## Non-Goals
- 全蔵書が貸出中の書誌に対する順番待ち予約
- 予約一覧の確認および取消
- 取り置き期限の管理
- 予約完了通知
- 予約した蔵書の貸出処理
- 司書向け予約管理
