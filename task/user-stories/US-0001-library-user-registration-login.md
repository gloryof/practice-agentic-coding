# US-0001: 図書館利用者として登録しログインを開始できる

## Status
Done

## User Story
As a 図書館利用者,  
I want メールアドレスとパスワードで利用登録したい,  
so that サービスにログインして本の探索や予約機能を使い始められる.

## User Benefit
登録とログイン開始までの手順を最小化することで、図書館利用者が迷わずサービス利用を開始できる。ログイン可能になることで、本の探索や予約といった価値提供機能へスムーズに到達できる。

## Acceptance Criteria
- [x] 未登録のメールアドレスと有効なパスワードを入力すると、登録が完了する。
- [x] 登録成功後、同一の認証情報で直ちにログインできる。
- [x] ログイン成功後は、タブを閉じたりブラウザを再起動したりしても、最長24時間、ログアウト、またはセッション期限切れのいずれか早い時点までログイン状態を利用できる。
- [x] ログアウトすると現在のログインセッションが終了し、そのセッションでは認証が必要な機能を利用できない。
- [x] 既に登録済みのメールアドレスでは登録できず、重複を示すエラーメッセージが表示される（HTTPステータスは `400`）。
- [x] 必須項目（メールアドレス、パスワード）が未入力の場合は登録できず、項目ごとのエラーが表示される。
- [x] メールアドレスに半角以外の文字が含まれる場合、またはパスワード要件未満の場合は登録できず、入力修正に必要なエラーが表示される。
- [x] 登録失敗時はアカウントが作成されない。
