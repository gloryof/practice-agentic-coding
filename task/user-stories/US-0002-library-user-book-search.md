# US-0002: 図書館利用者が蔵書を検索できる

## Status
Done

## User Story
As a 図書館利用者,  
I want 蔵書を検索したい,  
so that 来館前に読みたい本を見つけられる.

## User Benefit
図書館利用者が蔵書の有無や概要を素早く把握できることで、来館前に読みたい本を見つけやすくなり、読書体験の幅を広げられる。

## Acceptance Criteria
- [ ] ログイン済みの図書館利用者は、タイトル・出版社・著者名・ISBNで蔵書を検索できる。
- [ ] 複数の検索項目を入力した場合、AND条件で検索される。
- [ ] 検索結果一覧にタイトル・出版社・著者名・ISBNが表示される。
- [ ] ログインしていない場合は検索できず、ログインが必要である旨が表示される。
