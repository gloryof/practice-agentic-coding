# US-0003: 図書館利用者が来館前に貸出可否を判断できる

## Status
Todo

## User Story
As a 図書館利用者,  
I want 検索結果で蔵書の貸出可否を確認したい,  
so that 来館前に借りられる見込みを判断できる.

## User Benefit
図書館利用者が来館前に貸出可否を確認できることで、借りられない来館を減らし、時間と移動コストの無駄を抑えられる。

## Acceptance Criteria
- [ ] ログイン済みの図書館利用者は、検索結果の各蔵書について貸出可否（利用可/貸出中）を確認できる。
- [ ] 同一書誌に複数蔵書がある場合、少なくとも利用可能な蔵書があるかを判別できる。
- [ ] 在庫状態は準リアルタイム前提で更新され、古い状態を長時間表示し続けない。
- [ ] 非ログイン時は貸出可否表示にアクセスできず、ログイン導線が提示される。
- [ ] 在庫情報取得に失敗した場合、検索自体は継続しつつ、貸出可否のみ取得失敗と分かる。

## Non-Goals
- 予約確定機能
- 取り置き期限の管理

## Open Questions
- 準リアルタイムの許容遅延（何分以内）を何で合意するか
- 同一書誌の表示を在庫あり/なしの集約にするか、蔵書単位ステータスまで出すか
