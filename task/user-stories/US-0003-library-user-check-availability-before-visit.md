# US-0003: 図書館利用者が来館前に貸出可否を判断できる

## Status
Done

## User Story
As a 図書館利用者,  
I want 検索結果で蔵書の貸出可否を確認したい,  
so that 来館前に借りられる見込みを判断できる.

## User Benefit
図書館利用者が来館前に貸出可否を確認できることで、借りられない来館を減らし、時間と移動コストの無駄を抑えられる。

## Acceptance Criteria
- [x] ログイン済みの図書館利用者は、検索結果の各蔵書について貸出可否（利用可/貸出中）を確認できる。
- [x] 同一書誌に複数蔵書がある場合、在庫有無（1冊でも利用可能な蔵書があれば在庫あり）を判別できる。
- [x] 在庫情報は司書システム連携で更新される前提とし、本ストーリーではリアルタイム連携を要求しない。
- [x] 非ログイン時は貸出可否表示にアクセスできず、ログイン導線が提示される。
- [x] 在庫情報取得に失敗した場合、検索結果は返却せずエラー応答となる。
