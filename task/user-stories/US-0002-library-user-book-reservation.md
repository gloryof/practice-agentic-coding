# US-0002: 図書館利用者が本を予約できる

## Status
Todo

## User Story
As a 図書館利用者,  
I want 検索した本を予約したい,  
so that 読みたい本を確実に受け取れる.

## User Benefit
図書館利用者が見つけた本をその場で予約できることで、発見が実利用に直結し、サービスの価値を具体的に体験できる。

## Acceptance Criteria
- [ ] ログイン済みの図書館利用者は、キーワードで本を検索できる。
- [ ] 検索結果から本を選択し、予約を作成できる。
- [ ] 予約完了後、完了メッセージが表示される。
- [ ] ログインしていない場合は予約できず、ログインが必要である旨が表示される。

## Non-Goals
- 貸出処理
- 予約キャンセル
- 受取館選択・通知
- 司書向けの予約管理

## Open Questions
- 予約可能な在庫の判定基準（蔵書データの最小項目）が何か。
