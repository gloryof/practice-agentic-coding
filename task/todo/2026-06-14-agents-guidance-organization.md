# AGENTS.mdの参照導線と記述形式の整理

## ステータス
- Status: Proposed
- Updated: 2026-06-14 - 起票

## 背景
- ルート `AGENTS.md` の「参照ハブ」には各種ドキュメントの参照先が列挙されているが、どの依頼種別や作業場面で参照すべきかが分かりにくい。
- ルートとサブディレクトリの `AGENTS.md` で、共通ルールとディレクトリ固有ルールの責務境界が明確でない。

## 影響
- 作業開始時に必要な文書を選べず、参照漏れや不要な読み込みが発生する。
- 共通ルールがサブディレクトリの `AGENTS.md` にも重複し、変更時に内容が乖離する可能性がある。

## 対応案
- ルート `AGENTS.md` に、依頼種別と最初に参照するフローの対応を記載する。
- API 作業や設計方針レビューなど、作業条件に応じて追加参照する文書を明確にする。
- ルート `AGENTS.md` に共通ルール、サブディレクトリの `AGENTS.md` に固有ルールを配置し、重複または矛盾するガイダンスを整理する。

## 確認方法
- 代表的な依頼種別について、`AGENTS.md` だけで最初に参照すべきフローまたは正本文書を判断できることを確認する。
- 作業条件に応じて追加参照すべき文書を判断できることを確認する。
- ルートと `api/AGENTS.md` の適用範囲および優先順位が明確で、共通ルールの重複や内容の矛盾がないことを確認する。
