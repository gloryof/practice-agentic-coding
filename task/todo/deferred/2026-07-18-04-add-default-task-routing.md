# 未分類依頼向けの軽量ルーティングを追加する

## ステータス
- Status: Deferred
- Updated: 2026-07-19 - 練習プロジェクトの対象をユーザーストーリー・仕様・実装に限定するため保留
- Updated: 2026-07-18 - 起票

## 背景
ルート `AGENTS.md` の入口は、ユーザーストーリー・仕様と実装タスクに限定されている。文書やプロセスの改善、CI・ビルド・依存関係の保守、調査・診断、コンテキスト設計レビューなどは開始フローを一意に選べない。

## 影響
依頼によって参照文書や完了条件の選択がばらつき、実装フローを過剰適用したり、必要な共通ルールを見落としたりする可能性がある。

## 対応案
- 文書・プロセス改善、開発基盤保守、調査・診断を対象とする軽量な入口を定義する。
- 新規フローを追加するか、ルート `AGENTS.md` に最小限のデフォルト手順を置くかを、重複量を比較して決定する。
- 軽量ルートでは、対象領域の指示確認、影響範囲の探索、必要な検証、文書変更時の検査、完了報告を必須とする。
- 仕様や実装へ影響が広がった場合に既存フローへ移る条件を明記する。

## 確認方法
- 文書整理、CI失敗の診断、依存関係更新、AGENTSレビューの各例を一意にルーティングできることを確認する。
- 仕様判断または実装変更が必要になった場合、既存フローへ移行できることを確認する。

## 期限 / 優先度
- 期限: 未定
- 優先度: High
