# 図書館利用者が自分の予約一覧を確認できるようにする

現在は予約申込後に予約を一覧で確認できない。  
図書館利用者が自分の予約状況を確認できる状態にする。

## ステータス
- Status: Proposed
- Updated: 2026-10-25 - 起票

## 背景

`task/user-stories/US-0004-library-user-reserve-book-product.md` は予約申込を対象とし、予約一覧の確認と取消を対象外としている。  
現在の画面では、検索結果から予約を申し込み、成立直後の結果を確認できる。

## 課題

図書館利用者は画面を離れた後、自分の予約を確認できない。  
予約件数の上限に達した場合も、どの書誌を予約しているか画面から判断できない。

## 完了条件

- 図書館利用者がログイン後に自分の予約一覧を開き、予約した書誌と予約状況を確認できる。
- 他の図書館利用者の予約情報が表示されない。
- 予約がない場合にも、その状態が画面で分かる。
- 予約一覧のユーザーストーリーと関連するプロダクト仕様が整い、画面と API の振る舞いに反映されている。

## 実装方法案

- 予約一覧で表示する情報、予約状態の扱い、並び順をプロダクト仕様として決め、予約申込とは別のユーザーストーリーを作成する。
- 予約一覧を取得する API と、ログイン済み利用者向けの画面・導線を追加する。
- 未認証、予約なし、取得失敗、他の利用者の情報を参照できないことを検証する。
- 予約取消は本 TODO の対象に含めず、必要性と受け入れ条件を別途判断する。
