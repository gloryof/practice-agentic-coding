# 予約済み蔵書の確保解除条件を定義する

## ステータス
- Status: Proposed
- Updated: 2026-06-22 - 起票

## 背景
US-0004では、オンライン予約の成立時に利用可能な蔵書1冊を図書館利用者向けに確保する。一方、予約取消、取り置き期限、受取完了による予約終了は対象外であり、確保解除条件が未定義である。

## 影響
確保解除条件がないまま予約機能を運用すると、来館しない図書館利用者の予約によって蔵書が長期間利用できなくなり、他の図書館利用者の読書機会を損なう。

## 対応案
- 予約取消、取り置き期限切れ、貸出完了を予約終了条件として定義する。
- 各終了条件で予約状態と蔵書の確保状態を一貫して更新するユースケースを作成する。
- 図書館利用者と司書が確認できる予約状態を定義する。

## 確認方法
- 予約が各終了条件に到達したとき、蔵書が再び他の図書館利用者へ提供可能になることを受け入れ条件で確認する。
- 予約状態と蔵書状態に不整合が残らない失敗条件をユースケース仕様で確認する。

## 期限 / 優先度
- 期限: 予約機能の実装着手前
- 優先度: High
