# テストコードのリファクタリング

## ステータス
- Status: Done
- Updated: 2026-05-10 - 起票
- Updated: 2026-05-24 - 完了（テスト命名/グルーピング規約更新とテストコードのリファクタリング反映）

## 背景
- テストコードが仕様を表すようになっていない
- テストのグルーピング単位がメソッド単位や状態単位になっていない

## 影響
- 仕様を表すようになっていないため、どのようなテストをしたいのかが不明確

## 対応案
- テスト基準をブラッシュアップする
- テスト名のルール化
- ルール化に基づいてテストコードを修正

## 確認方法
- ルールファイルとテストコードのレビュー

## 期限 / 優先度
- 優先度: Medium
- 期限: 特になし
