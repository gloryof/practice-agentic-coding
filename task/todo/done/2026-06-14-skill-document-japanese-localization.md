
# スキル文書の日本語化

## ステータス
- Status: Done
- Updated: 2026-06-14 - 起票
- Updated: 2026-06-21 - スキル文書、参照テンプレート、チェックリストを日本語化
- Updated: 2026-06-21 - 新規・更新文書を日本語で記載するルールを追加

## 背景
- `.codex/skills` 配下には、スキル本体の `SKILL.md`、参照テンプレート、チェックリストが英語で記載されたものがある。
- 日本語中心のプロジェクト文書を参照しながらスキルを利用・保守する際に、言語の切り替えが必要になっている。

## 影響
- スキルの適用条件、ワークフロー、ガードレール、出力要件の理解に余分な認知負荷がかかる。
- スキルとプロジェクト文書で用語や説明の粒度が揃わず、レビュー時の認識差分につながる。

## 対応案
- `.codex/skills` 配下を棚卸しし、英語中心だった `SKILL.md`、参照テンプレート、チェックリストを日本語化した。
- YAML frontmatter はスキル名と発火条件を扱う機械可読メタデータであり、既存の適用条件との互換性を維持するため英語を保持した。
- `Critical`、`High`、`Blocker` などの重大度、`PK`、`FK`、`OWASP` などのコード・標準識別子は、レビュー基準との対応を維持するため英語を保持した。
- `Key Findings`、`Severity Assessment` などのセクション名とテンプレートのフィールド名は固定出力契約であり、利用側との互換性を維持するため英語を保持した。
- 日本語化前後でスキルの適用条件、ワークフロー、ガードレール、出力契約を変更していない。
- `AGENTS.md` に文書とスキル文書の日本語記載を必須とする言語方針を追加し、機械可読項目、コード識別子、正式名称、固定出力契約の例外条件を定義した。

## 確認方法
- 日本語化対象の文書に、固定出力契約や識別子を除く英語の見出し・本文が残っていないことを確認した。
- 各スキルが従来と同じ適用条件、ワークフロー、ガードレール、出力契約を維持していることを差分で確認した。
- スキル内の相対リンクと参照ファイルが有効であることを確認した。
- CodexのスキルValidatorとローカル絶対パス検査が成功することを確認した。
- `AGENTS.md` の言語方針により、今後の新規・更新文書にも同じ日本語化基準が適用されることを確認した。
