# Lighthouse CI経由のHigh依存を更新する

開発用Lighthouse CIを更新後も、プロキシ処理の依存経路にHighが4件残っている。  
互換性を検証して更新し、性能検査を安全に実行できる状態にする。

- Updated: 2026-11-23 - 05:33 UTCに再調査し、待機設定を維持した更新では差分がないことと、再開可能時刻を確認

- 優先度: 高

## 背景

Next.js 16.4.6と`@lhci/cli` 0.16.1へ更新後、npm auditはHigh 4件・Moderate 11件を検出した。  
Highの表示対象は`basic-ftp`、`get-uri`、`pac-proxy-agent`、`proxy-agent`である。  
`proxy-agent` 8.0.3、`pac-proxy-agent` 9.1.1、`get-uri` 8.0.2の公開日時は2026-11-16 18:35〜18:36 UTCであり、確認時点では公開後7日の待機期間を満たしていない。  
待機期間の設定を維持した`npm audit fix`では、修正版の経路へ更新されなかった。

今回の更新では既存API・DBの保護課題が未解決のため、性能検査を実行していない。  
API品質ゲートとAPI E2Eでバックエンドの回帰を確認し、フロントエンド品質ゲートと実APIブラウザE2Eで機能面を補完検証する。  
性能予算の確認は、下記の既存API・DB保護のTODOを解決した後に再開する。

## 課題

ブラウザ取得、アーカイブ展開、プロキシ解決、計測対象ページの処理が攻撃面になる。  
`@lhci/cli`は開発依存であり、通常のBFFの実行依存ではないが、性能検査では開発者権限で実行される。  
各アドバイザリの経路と到達条件の詳細評価は残っている。

## 完了条件

- High・Criticalが解消するか、項目ごとの影響評価と期限付きの明示的なリスク対応がある。
- 性能検査と既存フロントエンド品質基準を維持している。

## 実装方法案

- 2026-11-24 03:37 JST（2026-11-23 18:37 UTC）以降に`npm audit fix`で上記プロキシ依存の修正版を再解決する。
- [公式変更履歴](https://github.com/GoogleChrome/lighthouse-ci/releases)で確認した0.16系のLighthouse 13移行とproxy-agent更新について、待機期間を満たす依存の組み合わせで検証する。
- `npm explain`で各経路を確認し、安易なダウングレードや`--force`を使わず更新する。
- npm依存検査、署名検査、フロント品質ゲートを再実行する。
- 性能検査は[既存API・DB保護のTODO](../2026-10-25-02-protect-existing-api-during-frontend-performance-check.md)を解決してから実施する。

## 2026-11-23の再調査結果

更新は公開後7日の待機期間により未完了だが、管理者の指示により`Done`として終了した。  
依存更新や必須検証の成功を意味せず、この調査ではリスク受容や待機期間の例外を追加していない。

- Node.js 24の環境で`npm config get min-release-age`が`7`であることを確認した。
- `npm run audit:high`はHigh 4件・Moderate 11件で終了コード1だった。
- `npm explain`で`@lhci/cli@0.16.1` → `proxy-agent@8.0.2` → `pac-proxy-agent@9.1.0` → `get-uri@8.0.1` → `basic-ftp@5.3.1`の開発依存経路を確認した。
- `npm view <パッケージ>@<修正版> time --json`で下表の公開日時を確認した。
- `npm audit fix`は`up to date`となり、High 4件が残った。  
  `package.json`と`package-lock.json`に差分はない。

| パッケージ | 修正版 | 公開日時（UTC） | 公開後7日となる日時（JST） |
|---|---|---|---|
| `proxy-agent` | `8.0.3` | 2026-11-16 18:35:45.486 | 2026-11-24 03:35:45.486 |
| `pac-proxy-agent` | `9.1.1` | 2026-11-16 18:35:40.181 | 2026-11-24 03:35:40.181 |
| `get-uri` | `8.0.2` | 2026-11-16 18:36:23.226 | 2026-11-24 03:36:23.226 |

依存更新が成立していないため、今回の再調査では`npm ci`、署名検査、フロント品質ゲート、ブラウザE2Eを実施していない。  
再開後に依存差分を確認し、必須検証を実施する。  
性能検査の未実施理由と再開条件は背景および実装方法案のとおりであり、性能予算を満たすことは今回確認していない。
