# AGENTS指示の継承と優先順位を明確化する

## ステータス
- Status: Done
- Updated: 2026-07-19 - 継承モデルと競合時の優先順位を明確化
- Updated: 2026-07-18 - 起票

## 背景
ルート `AGENTS.md` は、より近い `AGENTS.md` がない場合のみルートをデフォルトとして適用するとも読める。一方、`api/AGENTS.md` はルートの指示を継承し、競合時のみ自身を優先すると定義している。

## 影響
`api/` 配下の作業でルートの仕様更新、文書言語、TODO起票、Gitステージングなどの共通ルールが適用されない解釈が生じる可能性がある。

## 対応案
- ルートから作業対象までに存在する `AGENTS.md` をすべて適用することを明記する。
- 指示が競合する場合のみ、作業対象に近い `AGENTS.md` を優先することを明記する。
- ルートと `api/AGENTS.md` の説明を同じ継承モデルへ統一する。

## 確認方法
- ルート直下と `api/` 配下の代表作業について、適用される指示を一意に説明できることを確認する。
- 共通ルールとAPI固有ルールが両方適用され、競合時の優先順位が明確であることを確認する。
- `./scripts/check-no-local-paths.sh` を実行する。
