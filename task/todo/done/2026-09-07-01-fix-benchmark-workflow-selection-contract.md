# ベンチマークの固定入力とワークフロー選択回答の契約を整合する

## ステータス
- Status: Done
- Updated: 2026-10-04 - ワークフロー選択が任意となり、選択回答の必須転送という前提がなくなったため完了
- Updated: 2026-09-07 - 起票

## 背景
`AGENTS.md`はワークフロー未指定時にユーザー選択を必須としている。  
一方、`agents/benchmarks/README.md`と`.codex/skills/agent-workflow-benchmark/SKILL.md`は、作業Agentへ渡す情報を固定計測契約とシナリオ本文だけに限定する。

シナリオ03の実行で、Coordinatorが受領済みの選択回答を履歴なしの作業Agentが参照できず、選択確認で止まった。  
今回は受領済み回答を追加転送して作業を続行し、正式基準値には不採用とした。

## 完了判断
- 現行の`AGENTS.md`ではワークフロー選択は任意であり、未指定時にユーザーの選択回答を必須とする旧前提は適用されない。
- したがって、ベンチマークの固定入力契約へ選択回答の転送形式を追加する対応は不要となった。  
  過去の計測結果と採否理由は変更しない。
- 現行条件での改善前後の再計測は`task/todo/2026-08-16-08-verify-agent-context-optimization.md`で扱う。

## 影響
ユーザーへの重複質問、計測の停止、実行ごとの追加入力による比較条件の不一致が生じる。  
成果物が完成しても固定条件の正式比較へ使用できない。

## 当初の対応案
ユーザーによる選択を維持しつつ、受領済み回答を作業Agentへ引き渡す形式・タイミング・計測区間を固定する。  
シナリオ本文に選択を固定する案と対話契約で扱う案を比較し、計測対象であるルーティング判断を不当に先取りしない方式を定める。  
既存の計測結果は上書きしない。

## 当初の確認方法
- Coordinatorで選択済みの実行と未選択の実行の双方で、質問の担当と回答の入力形式が一意に決まる。
- 履歴なしAgentが固定契約どおりに開始でき、重複質問や場当たり的な追加指示が不要になる。
- 新Baseline IDでシナリオ03を再計測し、入力と採否理由を記録する。
- `./scripts/check-no-local-paths.sh`が成功する。
