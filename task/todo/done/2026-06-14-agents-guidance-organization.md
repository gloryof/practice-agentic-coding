# AGENTS.mdの参照導線と記述形式の整理

## ステータス
- Status: Done
- Updated: 2026-06-14 - 起票
- Updated: 2026-06-21 - 参照導線、適用優先順位、ルートとAPI固有ルールの責務分離を確認

## 背景
- ルート `AGENTS.md` の「参照ハブ」には各種ドキュメントの参照先が列挙されているが、どの依頼種別や作業場面で参照すべきかが分かりにくい。
- ルートとサブディレクトリの `AGENTS.md` で、共通ルールとディレクトリ固有ルールの責務境界が明確でない。

## 影響
- 作業開始時に必要な文書を選べず、参照漏れや不要な読み込みが発生する。
- 共通ルールがサブディレクトリの `AGENTS.md` にも重複し、変更時に内容が乖離する可能性がある。

## 対応案
- ルート `AGENTS.md` に、依頼種別と最初に参照するフローの対応を記載した。
- API作業、設計方針レビュー、ドメイン仕様探索、スキル利用など、作業条件に応じて追加参照する文書を明確にした。
- ルート `AGENTS.md` に共通ルールと適用優先順位、`api/AGENTS.md` にAPI固有の開発ルール、検証、レビュー要件を配置し、責務を分離した。

## 確認方法
- ユーザーストーリー・仕様依頼と実装依頼について、ルート `AGENTS.md` だけで最初に参照するフローを判断できることを確認した。
- API作業、設計方針レビュー、ドメイン仕様探索、スキル利用について、追加参照する文書を判断できることを確認した。
- ルートと `api/AGENTS.md` の適用範囲および優先順位が明確で、共通ルールの重複や内容の矛盾がないことを確認した。
