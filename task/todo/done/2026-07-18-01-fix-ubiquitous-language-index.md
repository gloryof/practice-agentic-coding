# ユビキタス言語索引のリンクと掲載内容を修正する

## ステータス
- Status: Done
- Updated: 2026-07-18 - 起票
- Updated: 2026-07-19 - ユビキタス言語索引のリンク、掲載内容、見出しを修正して完了

## 背景
`product/ubiquitous/terms.md` の図書館利用者へのリンクは、索引ファイルから解決できないパスになっている。また、定義ファイルが存在する蔵書と書誌が索引に掲載されていない。

## 影響
正式語の探索に失敗したり、存在する用語定義を見落としたりするため、仕様・実装・レビューで表記や意味が揺れる可能性がある。

## 対応案
- 図書館利用者へのリンクを索引ファイルから解決できる相対リンクへ修正する。
- `product/ubiquitous/terms/term-book-item.md` と `product/ubiquitous/terms/term-book-product.md` を索引へ追加する。
- 索引内の見出しを次回更新時の言語方針に合わせて日本語化する。

## 確認方法
- 索引に図書館利用者、蔵書、書誌が掲載されていることを確認する。
- 索引内のMarkdownリンクがすべて存在するファイルへ解決できることを確認する。
- `./scripts/check-no-local-paths.sh` を実行する。
