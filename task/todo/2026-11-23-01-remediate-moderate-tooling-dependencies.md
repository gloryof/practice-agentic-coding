# Storybook・静的解析ツールのModerate依存を解消する

依存更新後も開発ツールの推移依存にModerateが11件残っている。  
公開修正版と互換条件を確認し、開発時の既知脆弱性を解消する。

## ステータス
- Status: Proposed
- Updated: 2026-11-23 - 依存ライブラリ更新後のnpm auditで確認
- 担当: リポジトリ管理者
- 再確認日: 2026-11-30

## 背景

Next.js 16.4.6、Storybook 10.6.7などへの更新後、npm auditはModerateを11件報告した。  
対象はStorybook経由の`glob`と、Storybook・TypeScript静的解析ツール経由の`minimatch`である。  
検査時点ではnpm auditに修正版の提案がなかった。

## 課題

`glob`のキャンセル回避と`minimatch`のパターン処理によるDoSが、開発時のファイル探索・解析処理へ影響する可能性がある。  
上位ツールの公開互換条件と公開後7日の待機期間を満たす修正経路が未確認である。

## 完了条件

- 対象の既知脆弱性が解消されるか、依存経路ごとの影響評価と期限付き対応方針がある。
- Storybookと静的解析の既存品質基準が維持されている。

## 実装方法案

- npm auditとnpm explainで上位ツールの修正状況と経路を再確認する。
- peer依存や公開後7日の待機期間を無視せず、互換性のある更新を適用する。
- 署名検査とフロントエンド品質ゲートで再確認する。
