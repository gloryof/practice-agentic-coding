# ドメインモデル仕様作成依頼

Scenario ID: `04-domain-model-specification`

成立した予約に72時間の有効期限を導入するため、予約コンテキストのドメインモデル仕様案を作成してください。

固定する業務判断は次のとおりです。

- 予約成立日時から72時間後を有効期限とする。時刻はUTCの瞬間として扱う。
- 現在時刻が有効期限より前なら予約は有効、有効期限と同じか後なら期限切れである。
- 有効期限の延長はできない。
- 期限切れになった予約が確保していた蔵書は、他の図書館利用者が利用できる状態へ戻す。
- 期限切れ処理では、予約ID、図書館利用者ID、書誌ID、蔵書ID、期限切れ発生日時を持つドメインイベントを生成する。
- 予約完了通知、予約一覧、手動取消、貸出処理、司書向け管理は対象外とする。

既存の予約モデル、関連イベント、ユースケース、制約との整合を確認し、正本へ反映可能なモデルの項目、振る舞い、不変条件、境界値、イベント仕様案を示してください。未確定のプロダクト判断が残る場合は推測せず分離してください。
