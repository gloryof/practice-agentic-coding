# ユーザーストーリー作成依頼

Book Vistaで、検索結果から選んだ書誌を起点に「関連する本」を見つけられる機能のユーザーストーリーを1件作成してください。

固定するプロダクト前提は次のとおりです。

- 対象者はログイン済みの図書館利用者である。
- 選択中の書誌と著者が同じ書誌を優先し、次に出版社が同じ書誌を候補とする。
- 選択中の書誌自身を除外し、重複を除いて最大5件を表示する。
- 候補がない場合は関連する本の一覧を表示しない。
- 個人の検索・貸出・予約履歴は使用しない。
- 外部の推薦サービスは使用しない。
- 予約、貸出、司書向け管理の振る舞いは変更しない。

ユーザー価値、検証可能な受け入れ条件、Non-Goals、残るOpen Questionsを明確にしてください。実装方法やAPI設計は決定しないでください。
