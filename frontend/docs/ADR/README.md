# フロントエンドアーキテクチャ決定記録

## 目的
フロントエンドの重要な設計判断について、背景、比較した選択肢、決定、影響を後から確認できるようにする。

## 管理方針
- ファイル名は `NNNN-<意思決定を表すkebab-case>.md` とする。
- 番号は既存 ADR の最大番号に1を加えた4桁の連番とする。
- 本文は日本語で記載する。
- 採用済み ADR の決定を変更する場合は既存 ADR を書き換えず、新しい ADR から置き換える ADR を参照する。
- 現在有効な実装規則は `frontend/docs/frontend-guidelines.md` を正本とし、ADRへ重複させない。
