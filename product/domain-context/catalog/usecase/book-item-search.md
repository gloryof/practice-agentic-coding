# ユースケース名
蔵書検索

## 目的
- 図書館利用者が蔵書の有無や概要を素早く把握し、来館前に読みたい本を見つけられるようにする。
- 既知の本だけでなく関連する本にも気づける入口を提供し、読書体験の幅を広げる。
- 利用可能な蔵書数を示し、来館前に借りられる見込みを判断できるようにする。

## タイプ
クエリ

## 入力
| 項目 | 必須 | 型・モデル | 制約 |
|---|---|---|---|
| タイトル | 任意 | 文字列 | 指定時は空白だけを許可しない。既定は部分一致 |
| タイトル完全一致 | 任意 | 真偽値 | タイトル指定時だけ `true` を指定できる |
| タイトルカナ | 任意 | 文字列 | 指定時は空白だけを許可しない。既定は部分一致 |
| タイトルカナ完全一致 | 任意 | 真偽値 | タイトルカナ指定時だけ `true` を指定できる |
| 出版社 | 任意 | 文字列 | 指定時は空白だけを許可しない。既定は部分一致 |
| 出版社完全一致 | 任意 | 真偽値 | 出版社指定時だけ `true` を指定できる |
| 出版社カナ | 任意 | 文字列 | 指定時は空白だけを許可しない。既定は部分一致 |
| 出版社カナ完全一致 | 任意 | 真偽値 | 出版社カナ指定時だけ `true` を指定できる |
| 著者名 | 任意 | 文字列 | 指定時は空白だけを許可しない。既定は部分一致 |
| 著者名完全一致 | 任意 | 真偽値 | 著者名指定時だけ `true` を指定できる |
| 著者名カナ | 任意 | 文字列 | 指定時は空白だけを許可しない。既定は部分一致 |
| 著者名カナ完全一致 | 任意 | 真偽値 | 著者名カナ指定時だけ `true` を指定できる |
| ISBN | 任意 | 文字列 | 完全一致 |

検索条件は1項目以上必須とし、複数指定した場合は AND 条件で検索する。

## 出力
検索条件に合致する書誌ごとに次の項目を持つリストを返す。

| 項目 | 型・モデル | 説明 |
|---|---|---|
| タイトル | 文字列 | 蔵書のタイトル |
| 出版社 | 文字列 | 蔵書の出版社 |
| 著者名 | 文字列のリスト | 蔵書の著者名 |
| ISBN | 文字列 | 蔵書の ISBN |
| 利用可能数 | 数値 | 現在利用可能な蔵書数 |
| 総蔵書数 | 数値 | 図書館が所蔵する総数 |

## 失敗条件
- 認証済みのアクセストークンがない場合はログイン必須エラーとする。
- 検索条件が1件もない場合は入力チェックエラーとする。
- 検索値が空白だけの場合は該当項目の入力チェックエラーとする。
- 完全一致指定だけがあり、対応する検索値がない場合は入力チェックエラーとする。
- 完全一致指定に `true` 以外を指定した場合は入力チェックエラーとする。

## フロー
1. アクセストークンを検証する。
2. 検索条件と完全一致指定を検証する。
3. 指定された条件を AND で組み合わせて蔵書を検索する。
4. 書誌情報、利用可能数、総蔵書数を結果として返す。
