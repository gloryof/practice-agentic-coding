# ユースケース名
図書館利用者登録

# タイプ
コマンド。

# 入力項目
| 項目名     | 対応するモデル                                  |
|---------|------------------------------------------|
| メールアドレス | [メールアドレス](../domain/model/email.md)      |
| パスワード   | [パスワード](../domain/model/raw-password.md) |

# 出力項目
| 項目名      | 対応するモデル                                        |
|----------|------------------------------------------------|
| 図書館利用者ID | [図書館利用者ID](../domain/model/library-user-id.md) |
| パスワード    | [パスワード](../domain/model/raw-password.md)       |
| 登録日時     | 日時。                                            |


# フロー
1. 入力項目が制約を満たしているかをチェックする
   1. 満たしていない場合は入力チェックエラーで終了
2. メールアドレスが登録済みでないかをチェックする
   1. 満たしていない場合はメールアドレス重複エラーで終了
3. [図書館利用者登録イベント](../domain/event/library-user-registered.md) を発行する
4. 出力項目を返す
