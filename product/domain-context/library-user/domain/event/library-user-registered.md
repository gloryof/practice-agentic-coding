# イベント名
図書館利用者登録イベント

## 発生タイミング
入力検証とメールアドレス重複確認に成功し、図書館利用者IDを発行したとき。

## 項目
| 項目 | 必須 | 型・モデル | 説明 |
|---|---|---|---|
| 図書館利用者ID | 必須 | [図書館利用者ID](../model/library-user-id.md) | 新しく発行した利用者ID |
| メールアドレス | 必須 | [メールアドレス](../model/email.md) | 登録するメールアドレス |
| 発生日時 | 必須 | 日時 | 登録が成立した日時 |

## 発行後の処理
- [図書館利用者](../model/library-user.md)を保存する。

入力パスワードと認証情報の作成はイベントへ含めず、図書館利用者登録ユースケースが認証情報発行契約を通じて同一トランザクション内で実行する。
