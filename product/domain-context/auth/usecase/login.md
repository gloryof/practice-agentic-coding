# ユースケース名
ログイン。

# タイプ
コマンド。

# 入力項目
| 項目名     | 対応するモデル                                  |
|---------|------------------------------------------|
| メールアドレス | [メールアドレス](../domain/model/email.md)      |
| パスワード   | [パスワード](../domain/model/raw-password.md) |

# 出力項目
| 項目名        | 対応するモデル     |
|------------|-------------|
| アクセストークン   | 文字列。   |
| トークンタイプ    | 文字列（Bearer） |
| 期限切れまで残り秒数 | 数値。         |


# フロー
1. 入力項目が制約を満たしているかをチェックする
   1. 満たしていない場合は入力チェックエラーで終了
2. メールアドレスが存在するかチェックする 
   1. 存在していない場合は認証エラーで終了
3. パスワードがあっているかチェックする
   1. あっていない場合は認証エラーで終了
4. [図書館利用者登録イベント](../domain/event/logged-in.md) を発行する
5. 出力項目を返す
