# イベント名
ログインイベント。

# 発生タイミング
図書館利用者がシステムにログインした時。

# 項目
| 項目名      | 必須 | モデル                                    |
|----------|----|----------------------------------------|
| 認証されたアカウント | ○  | [認証されたアカウント](../model/auth-account.md) |
| メールアドレス  | ○  | [メールアドレス](../model/email.md)           |
| 登録日時     | ○  | 日時                                     |

# イベント発行時に記録される情報
- ログインセッション
  - トークン
  - [図書館利用者ID](../model/library-user-id.md)
  - 失効日時
