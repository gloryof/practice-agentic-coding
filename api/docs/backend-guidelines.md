# APIバックエンドガイドライン

## 目的
- 本規約は、コミュニティ図書館向けサービスのバックエンド開発における判断基準を統一し、APIの一貫性・保守性・運用品質を高めるための標準である。

## 適用範囲と基本方針
- `MUST` 本規約はバックエンド全体に適用する。
- `MUST` 作業開始時に `api/AGENTS.md` を最初に参照し、本ガイドと併せて従う。
- `SHOULD` 新規コードだけでなく、既存コード変更時にも可能な範囲で本規約へ寄せる。

## 詳細
このドキュメントは人やAIがバックエンドのガイドラインを知るための入り口のドキュメントとする。  
それぞれの詳細はリンク先のドキュメントを参照すること。
各ドキュメントの参照条件を設定しているため、その参照条件を厳守すること。
