# アーキテクチャ決定記録

## 目的

アーキテクチャに影響する重要な意思決定について、背景、比較した選択肢、決定内容、影響を後から確認できるようにする。

## ADRを作成する基準

次のいずれかに該当する場合はADRを作成する。

- `MUST` 新しいライブラリを追加した場合。
- `MUST` 全体的なパッケージ構成を変更した場合。
- `MUST` AIがアーキテクチャ上の意思決定を記録する必要があると判断して提案し、人間が承認した場合。

AIがADR作成を提案する場合は、必要と判断した理由、影響範囲、主要な選択肢を人間へ提示する。人間の承認を得るまではADRを作成済みとして扱わない。

## ファイルの管理

- ファイル名は `NNNN-<意思決定を表すkebab-case>.md` とする。
- 番号は既存ADRの最大番号に1を加えた4桁の連番とする。
- 本文は日本語で記載する。
- 採用済みADRの決定を変更する場合は、既存ADRを直接書き換えず、新しいADRから置き換えるADRを参照する。
